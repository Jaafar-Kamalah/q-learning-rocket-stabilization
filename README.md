# q-learning-rocket-stabilization
This project uses table-based Q-learning to control a simulated rocket with three on/off engines (left, middle, right). The state is made of the discretized angle, horizontal velocity and vertical velocity, and the reward is highest when the rocket is upright and standing still. A demo of the application is available at: https://www.youtube.com/watch?v=7JSJvBL1Wnw

## QLearningController Keybinds
- **E** - Toggle exploration on/off
- **M** - Toggle graphics on/off for faster simulation
- **R** - Pause/resume simulation
